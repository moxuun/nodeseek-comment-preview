# 星渊 NodeSeek 楼中楼与预览

只保留楼中楼、原版布局、紧凑首页预览和预览内阅读跳转四个紧密相关的功能：

- 帖子页：楼中楼、原版评论布局切换，并读取同一帖子的其他分页来补齐引用关系。
- 首页/节点列表：普通左键点击帖子标题打开站内预览弹窗；弹窗里的回复同样按楼中楼展示，不是平铺摘要，也不直接跳转。
- 预览主帖（#0）提供点赞、加鸡腿、反对、收藏、引用、回复六个操作；回复楼层只提供点赞、加鸡腿、反对、引用、回复，不显示楼层收藏。收藏沿用 NodeSeek 的帖子收藏接口，因此收藏对象始终是当前帖子。所有会改变账号状态的操作都只有用户点击后才会请求 NodeSeek，引用和回复会在弹窗底部打开编辑区。
- 预览弹窗右下角提供论坛风格的圆形上下箭头按钮：弹窗内容滚动超过 300px 后显示，分别跳转预览顶部和底部；主页面不会显示这两个按钮。
- 预览采用紧凑排版：压缩主帖、作者信息、正文、回复卡片和楼中楼缩进的间距，让首屏显示更多内容；该样式只作用于预览弹窗。
- 预览会移除评论头部无效的灰色楼层按钮，把发布时间与作者信息排列在同一行，并将跨页来源链接放到评论卡片右上角。
- 预览图片支持点击放大、滚轮缩放、拖动、Esc 关闭，并提供“打开原图”入口；右下角上下按钮会避开弹窗滚动条。
- 预览框占满可视高度，并保留更宽的左右灰色边距；点击灰色区域仍可退出预览，也可以通过右上角关闭按钮或 Esc 退出。
- 标题栏提供“回复帖子”，不携带楼层引用；评论卡片中的“回复”仍然是回复对应楼层。
- 预览框最右侧提供刷新、回到顶部、回到底部三个按钮；刷新沿用 V2Next 的体验：保留当前内容，在后台重新读取帖子及楼中楼，刷新按钮单独显示加载状态，成功后替换内容，不会跳转页面。
- 预览首屏先渲染当前分页，其他分页并发懒加载；分页并发上限为 4，评论卡片使用浏览器懒渲染，减少首次等待和长帖渲染压力。

Ctrl/Command 点击、鼠标中键和右键菜单保持 NodeSeek 原生行为。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 打开 `xingyuan-nodeseek-enhancer.user.js` 并安装。
3. 刷新 NodeSeek 页面。

脚本使用 `@grant none`，不加载远程模块，不执行远程代码。

## 使用

帖子页评论区上方有两个按钮：

- `楼中楼`：识别 `@用户 #楼层`，把回复嵌套到对应楼层，并读取最多 12 页同帖评论。
- `原版`：恢复当前页面由 NodeSeek 输出的原始评论顺序和布局。

列表页普通点击帖子标题会打开预览；预览会先显示主帖 #0，再读取同帖分页并重建楼中楼。主帖底部有完整六项操作，回复楼层底部没有收藏项。点击“引用”或“回复”可在弹窗编辑并发送，点击“打开原帖回复”可回到 NodeSeek 原生编辑器；弹窗内也可以点击“新标签打开”进入原帖。

## 故障排查

如果楼中楼读取失败，可以点击 `原版`，脚本会恢复当前页面原始评论。Cloudflare、网络超时或登录状态可能导致跨页读取失败。

如果首页点击仍然跳转，请先确认旧版本脚本已卸载或更新到 `0.4.6`，然后强制刷新页面。

预览图片会使用 NodeSeek 来源嵌入，避免被图片站误判为直链；如果图片站仍拒绝嵌入，弹窗会显示失败提示。

## 安全边界

- 只读取当前 NodeSeek 帖子页面的同源 HTML。
- 不读取 Cookie、密码、令牌、剪贴板、私信或浏览历史。
- 不自动点赞、回复、感谢、签到、关注或发送通知；点赞、鸡腿、反对、收藏和发送回复都必须由用户主动点击。
- 远程评论先经过清理再显示；预览克隆只接管上述操作栏，帖子页当前页原生评论菜单不被脚本改写。
