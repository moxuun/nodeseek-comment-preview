# 星渊 NodeSeek 增强

一个独立的 Tampermonkey/Violentmonkey 用户脚本，把 V2EX Next 的核心阅读交互迁移到 NodeSeek：楼中楼、跨页评论、V2 原版/最热/只看楼主视图、帖子弹窗、长正文折叠、图片灯箱、暗色适配、自动宽度和 Base64 解码。

## 安装

1. 安装 Tampermonkey、Violentmonkey 或其他用户脚本管理器。
2. 打开 `xingyuan-nodeseek-enhancer.user.js`。
3. 在脚本管理器中确认安装。
4. 打开或刷新 `https://www.nodeseek.com/`。

脚本只匹配 HTTPS 的 `www.nodeseek.com`，不需要额外的 `@connect`、`@require` 或特权权限。

## 使用

- 帖子页会显示“评论视图”工具栏，可切换“楼中楼”“V2 原版”“最新”“最热”“只看楼主”。右下角“星渊”按钮可以打开设置。
- 楼中楼默认按 NodeSeek 楼层顺序重组；每组默认最多显示 15 条回复，超过数量或超过最大层数的回复可展开。
- 跨页评论只读取当前帖子，默认最多读取 12 页；原始评论会先正常显示，读取完成后再整理，读取失败时保留原始布局。
- 列表页普通点击帖子标题会打开正文预览弹窗；Ctrl/Command 点击、中键点击和右键菜单仍保持原生新标签页行为。列表卡片不会被插入摘要块。
- “最热”按 NodeSeek 当前评论菜单中的“点赞”数量排序；“只看楼主”只保留能识别到的楼主评论。
- 选中正文中的标准 Base64 字符串后会出现“点击解码”工具；脚本不读取剪贴板。
- 点击正文或评论中的普通图片可以放大；头像、表情和装饰图片不会触发灯箱。
- 脚本不会自动点赞、感谢、回复、签到、关注或发送通知。

## 故障排查

### 安装后没有效果

确认脚本管理器已启用该脚本，然后刷新 NodeSeek 帖子页。若使用了 NodeSeek 的其他增强脚本，先暂时停用它们以排查 DOM 或样式冲突。

### 楼中楼一直加载

NodeSeek 可能被 Cloudflare、网络策略或登录态拦截。可以在设置中关闭“整理楼中楼”，页面会恢复原始评论布局；也可以降低“最多读取评论页数”。

### 部分回复没有归入楼中楼

脚本只识别 NodeSeek 页面中明确的 `@用户 #楼层` 引用。没有标准楼层链接、引用已被删除或引用跨帖时，会作为普通评论保留。

### 弹窗加载失败

点击“新标签打开”或关闭脚本的“点击帖子标题打开弹窗”选项即可回到 NodeSeek 原生打开方式。

## 安全边界

- 不读取 Cookie、密码、令牌、剪贴板、私信或浏览历史。
- 不加载远程模块，不执行远程代码。
- 只对同一 NodeSeek 帖子执行同源 GET 请求。
- 远程分页 HTML 会移除脚本、表单、事件属性、危险 URL、内嵌框架和依赖 Vue 状态的评论菜单后再显示；当前页仍保留 NodeSeek 原生菜单。
- 账号相关行为只保留 NodeSeek 原生页面中由用户主动点击触发的操作。
