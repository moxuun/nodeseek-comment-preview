# 星渊 NodeSeek 楼中楼与预览

只保留楼中楼、原版布局、首页预览和阅读跳转四个紧密相关的功能：

- 帖子页：楼中楼、原版评论布局切换，并读取同一帖子的其他分页来补齐引用关系。
- 首页/节点列表：普通左键点击帖子标题打开站内预览弹窗；弹窗里的回复同样按楼中楼展示，不是平铺摘要，也不直接跳转。
- 预览评论保留/补齐点赞、加鸡腿、反对、收藏、引用、回复操作栏；前四项只有用户点击后才会请求 NodeSeek，引用和回复会在弹窗底部打开编辑区。收藏沿用 NodeSeek 的帖子收藏接口，因此收藏对象是当前帖子。
- 页面右下角提供论坛风格的圆形上下箭头按钮：滚动超过 300px 后显示，分别跳转顶部和底部；窄屏会自动缩小并靠近边缘。

Ctrl/Command 点击、鼠标中键和右键菜单保持 NodeSeek 原生行为。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 打开 `xingyuan-nodeseek-enhancer.user.js` 并安装。
3. 刷新 NodeSeek 页面。

脚本使用 `@grant none`，不加载远程模块，不执行远程代码。

## 使用

帖子页评论区上方有两个按钮：

- `楼中楼`：识别 `@用户 #楼层`，把回复嵌套到对应楼层，并读取最多 12 页同帖评论。
- `原版`：恢复当前页面由 NodeSeek 输出的原始评论顺序和布局。

列表页普通点击帖子标题会打开预览；预览会读取同帖分页并重建楼中楼；每条预览评论底部都有操作栏。点击“引用”或“回复”可在弹窗编辑并发送，点击“打开原帖回复”可回到 NodeSeek 原生编辑器；弹窗内也可以点击“新标签打开”进入原帖。

## 故障排查

如果楼中楼读取失败，可以点击 `原版`，脚本会恢复当前页面原始评论。Cloudflare、网络超时或登录状态可能导致跨页读取失败。

如果首页点击仍然跳转，请先确认旧版本脚本已卸载或更新到 `0.3.4`，然后强制刷新页面。

预览图片会使用 NodeSeek 来源嵌入，避免被图片站误判为直链；如果图片站仍拒绝嵌入，弹窗会显示失败提示。

## 安全边界

- 只读取当前 NodeSeek 帖子页面的同源 HTML。
- 不读取 Cookie、密码、令牌、剪贴板、私信或浏览历史。
- 不自动点赞、回复、感谢、签到、关注或发送通知；点赞、鸡腿、反对、收藏和发送回复都必须由用户主动点击。
- 远程评论先经过清理再显示；预览克隆只接管上述操作栏，帖子页当前页原生评论菜单不被脚本改写。
